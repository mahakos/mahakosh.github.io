# Neesil website

Source for https://mahakos.github.io/mahakosh.github.io/ (GitHub Pages, plain HTML and CSS, no build step).

- `index.html`: home page
- `services.html`: the six services, engagement models and typical prices, tools and protocols
- `work.html`: five case studies, one per block in [mahakos/verikosh](https://github.com/mahakos/verikosh)
- `start.html`: how a project starts, a brief form that writes an email (nothing is stored), confidentiality rules, NDA summary and business details
- `report.html`: sample verification health-check report, written on the open APB3 design
- `assets/tokens.css`, `assets/base.css`, `assets/site.css`: the design system (Hallmark Wayfind: Chivo Mono, square ink rules, cobalt actions, amber figures on ink)
- `404.html`, `robots.txt`, `sitemap.xml`: housekeeping. Add every new page to `sitemap.xml`.

Every number on the site should come from running code in the verikosh repo. If a result changes, update the page.
Prices on `services.html` are typical ranges; update them when real quotes move.
