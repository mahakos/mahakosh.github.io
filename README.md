# Neesil website

Source for https://mahakos.github.io/mahakosh.github.io/ (GitHub Pages, plain HTML and CSS, no build step).

- `index.html`: home page
- `report.html`: sample verification health-check report, written on the open APB3 design in [mahakos/verikosh](https://github.com/mahakos/verikosh)
- `assets/site.css`: shared styles (light and dark themes)
- `404.html`, `robots.txt`, `sitemap.xml`: housekeeping

Every number on the site should come from running code in the verikosh repo. If a result changes, update the page.
